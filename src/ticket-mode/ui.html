New runs

The default for tickets you queue. The Pick footer can choose otherwise for one batch. A run already on the queue keeps its own.

Planning

A ticket queued with Plan first is planned on these before it runs. Planning decides for you, so it usually wants the most capable model.

New ticket

Say what the ticket is for, in plain words. A writer reads the repositories and the tracker, checks for a duplicate, and writes drafts for you to review. Nothing is created until you approve a draft.
