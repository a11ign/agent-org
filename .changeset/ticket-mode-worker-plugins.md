Ticket mode reads `tickets.plugins`, the Claude Code plugins every worker runs with, and enables them in each worker's own settings file: a worker starts in its ticket's folder, where none of the person's project settings apply. Workers are no longer told they have no browser, so a machine whose tools can take screenshots gets them in its draft pull requests, and the hook no longer refuses one machine's screenshot skill by name.
