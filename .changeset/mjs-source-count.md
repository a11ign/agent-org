The number of `.mjs` source files the tool has can no longer rise (a11ign/a11ign#3556, toolchain row 4d of #3550). `src/packaging/mjs-source-count.test.ts` pins 203 non-test `.mjs` files (under `src/` outside `src/packaging/`, `host/` and `.github/`) and 43 `*.test.mjs`, read at `58a159c` (204 and 43) less the one file this change converts, and fails when either count rises, naming the files the change added against its base (the merge group's first parent, or the merge-base with `origin/main`) where that base can be read. A drop passes and says the pin can be lowered, so two conversions merged together stay green. The refusal and the README carry the rule: a new source file is `.ts`, unless a shipped command imports it; then raise the pin in the same diff and say why. A touched `.mjs` may convert in the same pull request.
