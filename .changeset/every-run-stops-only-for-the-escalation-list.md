One escalation list decides what reaches a person (A11-257). A planner no longer stops for a "behaviour grill": it settles everything off the list itself, taking the option it would have recommended, writes `**Behaviour:** settled by the planner` for a screen with each decision and its reason, and a `Product:` bullet under "Decisions made without a person" is no longer a defect. A worker never stops to ask about anything off the list: an unplanned choice goes under "Decisions made without a person" in its pull request. A `needs-human` outcome names its item in `escalation` and a `QUESTION.md` starts with `**Escalation:** <id>`; the Stop hook refuses a stop that names none (a Talk session, a new-ticket run and a publish run are exempt), and the card starts with the item's words, or "Off the escalation list:" for a stop that got past the hook's bound. Pick no longer holds a ticket for an open decision or an ungrilled screen. A review that requests changes against the plan or the ticket's Decisions is answered with a reply that quotes the decision and the round ends `reviewed`. The reviewer is bound by the plan's decisions as well as the ticket's, ranks the ticket's Decisions first, and writes a note and not a finding where it disagrees (reviewer contract 1.8: `ReviewBrief.planDecisions` and `ReviewBrief.escalation`).
