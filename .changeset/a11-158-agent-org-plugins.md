Every external concern of ticket mode is now an **agent-org plugin**: a code module behind a versioned contract (tracker, code host, publisher, reviewer, exposure, messaging), found in a registry and loaded only when enabled. `agent-org plugin list|install|enable|disable|uninstall|config` manages them and writes `tickets.providers.<concern>` through the Settings page's own path (your notes and layout kept, a refused file never written, `host.json.bak` beside it). `tickets.providers.<block>.enabled` is new (absent is true, so no host file changes): disabling the publisher publishes nothing, disabling the reviewer starts none, and disabling the exposure serves the board on loopback only. The only tracker and the only code host cannot be disabled or uninstalled, by name. A plugin that implements a contract major this agent-org does not read is refused by name at start and in `agent-org doctor`, which also names each plugin, says whether it is disabled, runs an enabled bundled plugin's checks and shows messaging. Today's providers stay in core as built-in plugins, so no live host file needs a change; each moves into `plugins/<name>` in its own release.
