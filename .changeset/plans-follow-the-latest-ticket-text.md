A plan is stamped with the text of its ticket and written again before its worker starts when the description changes (A11-167, ADR 0005); every brief says which text of the ticket it carries; a change while a worker runs is sent to it; and a dependent's planner is given what its blockers' merged pull requests found. Tracker contract 1.3 adds `updatedAt`, `texts` and `detachPlan`, and code host contract 1.4 adds `readMergedFindings`; both are optional.
