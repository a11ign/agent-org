The liaison can record what the chairman said on a row and fix what he says is wrong, through two commands and nothing else (a11ign/a11ign#3417). `chairman:record --row=N --message=<ref>` (his words on stdin) writes one row comment, quoted with its HTML comment markers escaped and opening `Recorded by liaison from the chairman's message <ref>; not written by the chairman`: it never carries the listener's `Chairman answered via Telegram` line, which only the listener may write. `chairman:correct --row=N --message=<ref> --as=withdraw|reroute|re-ask` is a closed set: `withdraw --reason=stale|wrongly-labelled|already-done` removes `needs:chairman` with a comment and writes a `withdraw` ledger line; `reroute` sets `answer:product-manager` and no other label; `re-ask` writes a new brief, refused unless the watcher would send an alert for it. Every command refuses a `--message` ref that is not an accepted inbound line in the ledger, and (but for a `re-ask`'s brief) words that are not the ones the ledger hashed, so nothing is written for a message the chairman did not send; a failure between two steps is resumed by the next call and not repeated. An agent with a shell can still write any comment with `gh`: this makes a recorded answer detectable against the chairman's chat, not impossible.
