The reviewer's hand-off is one its App can perform, and an Acceptance that fails as written is `not convinced` (agent-org#1398, chairman class 3, a11ign/a11ign#928). The door refused `not convinced (environment)` with "hand the row to orchestrator", a label the reviewer App cannot write (no Issues write), so the refusal reached nobody. It now refuses an `(environment)` verdict only when it quotes no command, and names the verdict file, which the gate reads, as the hand-off. `row-review` says an Acceptance that fails as written is `not convinced`, with its command quoted, and that `(environment)` is for a failure that disappears outside the sandbox.
