`agent-org ticket:pair` pairs the worker terminal as well as the board. With `tickets.serve` set and `tickets.terminal` on this machine it prints the board's code and then the terminal's, from herdr web ui's own `pair` run with the terminal service's variables, so no path is typed; `--terminal` prints the terminal's alone and `--board` the board's. A paired browser that follows a run's "Open terminal" link is redirected, with a terminal pairing code in the address, when this machine's terminal can mint one; otherwise the link goes out plain, as before. `onboard`'s last message, `doctor`'s new `pairing` check and the README say how to pair a new device for both.
