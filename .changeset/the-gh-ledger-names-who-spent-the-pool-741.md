The `gh` call ledger can name who spent the pool, per hour (a11ign/a11ign#4148 residual, a11ign/agent-org#741). `host/gh` took the ledger's caller from the calling process's command line cut to 160 characters BEFORE the `--import .../crash-exit.ts` preload every unit starts under, which alone is about 100 of them, so the script's name never reached the reader (19% of one afternoon's list calls read `work-g`/`work-t`, 9% a bare `node`); it now takes the preload out first. The `<ledger>.hourly` rollup gains a seventh field, the caller's script, so a per-caller reading survives the 2 MiB trim: `gh-ledger.ts <ledger> --per-hour --top <n>` prints each hour's top callers beside its total. A six-field rollup line (from before this) is read as it always was, kept six fields by the next trim, and named `(caller not recorded)`, never given a guess. After install (`host:install`) the wrapper on the host is the new one; `host:check` reports DIVERGED until then.
