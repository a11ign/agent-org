The worker stop hook's bound names the block an answer has since cleared (agent-org#1687, agent-org#1693). When a worker's turn ends again after a BLOCKED declaration on its row was answered, the declared reason now quotes that block's first line: `second bound after an answered block (<first line>); the turn ended again with no pull request and no declaration`. A row with no answered earlier block keeps today's text byte for byte, and a block still owed an answer, or one whose time cannot be read, keeps it too. A ruling on the restated block still writes the declaration and no label or comment.
