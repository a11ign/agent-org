GitHub is now a bundled **agent-org plugin**, `plugins/github`, behind the code host contract (version 1.1), and ticket mode's reads of a pull request go through it: the feedback on a run's pull requests and the account the workers act as, the reviewer's reading of a pull request (its head, reviews, trust and whether its checks settled) and its state, a repository's open pull requests, and the stacked-pull-request retarget sweep. The stacking-extension doctor rows (`gh stack` and `stacked pull requests`), onboard's step that installs the extension, and what `agent-org update` keeps true for it moved into the plugin with their words unchanged, and `ticket:stack-live-check` now runs from `plugins/github`. Core loads the enabled code host once at start (`ticket:serve`, `ticket:review`), imports no plugin's code, and builds its tests on `fake-codeHost`. The contract grows by `readPullFeedback`'s list of accounts whose feedback is ignored besides the board's own (the reviewer's); a plugin may export `keep` (what `agent-org update` keeps true), and is given the host's `clones`, `policy` (what core decides about checks and the reviewer's trust) and an `env` for a program it runs. The built-in `github` row and its pin are gone. `docs/gh-call-baseline.json` and its ratchet now cover `scripts/`, `plugins/` and every shell script, and exempt `plugins/github/`: the rest of A11-160 moves the remaining GitHub calls in, one pull request at a time, and the baseline only goes down. No host file changes: `provider: "github"` and a missing code host block both resolve to the bundled package.
