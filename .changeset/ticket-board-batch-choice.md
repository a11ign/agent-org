The ticket board's Pick footer chooses the model and effort for the batch about to be queued. They start as the default from Settings, and changing them applies to that batch only: the default is not saved, runs already queued keep their own, and the next batch starts from the default again. The footer says when a batch differs from the default and offers Use the default. A queue the board refuses keeps the batch's choice. The Pick tab's top bar now wraps, so the page fits a phone's width.
