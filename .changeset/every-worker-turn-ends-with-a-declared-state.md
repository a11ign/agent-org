A worker's turn ends with a declared state, and an idle worker without a fresh one is stalled (a11ign/agent-org#460, epic #4437, class `worker-state-ambiguous`). **New command `agent-org worker:state <state>`** with exactly four states: `waiting-ci <pr>`, `waiting-review <pr>`, `done` and `blocked <row> <reason>`. It refuses an unknown state, a missing pull request or row, and `blocked` without a reason, each by name, and writes nothing. The declaration (session, state, ref, time) is one file per session under `<state dir>/worker-state/`, which the gate reads with no model call.

**What changes for a pinned project.** An idle or `done` claimed worker is excused only by a FRESH declaration (newer than the start of its last turn, which is the last prompt delivered to it, else its claim) whose condition still holds: `waiting-ci` while that pull request is open with a check running; `waiting-review` while it is open and not at changes-requested; `done` while the row is closed or a pull request of the claim merged; `blocked` while the row carries the `answer:<session>` label of the session it was declared on, `--to` or else `product-manager`, and no other (the command applies the label itself, creating it where the repository lacks it, and posts the reason). A worker with none is sent "continue" at #458's 10-minute figure, not the 45-minute clock, and its ledger line is `claimed-worker-stalled`; the nudge says whether it declared nothing, declared before its last turn, or declared something no longer true. **This replaces three inferences with the declaration**: an open pull request with a pending check, a live `reviewer-<n>`, and #4017's one-interval grace for a young pull request no longer excuse a holder that declared nothing. Where the state directory cannot be READ (as opposed to being empty) the older rules stay, because absence is not proof.

A session herdr reports `blocked` is sent the instruction to declare `blocked <row> <reason>` or decide and record why, ONCE per stall (the memory is `blocked-told.json` in the host's state directory), instead of a `BLOCKED` log line every tick; a session that stops being blocked and blocks again is told again. Only `worker-*` sessions are sent it.
