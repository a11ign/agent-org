A Grill new-ticket run whose agent ends its turn on a question is Waiting for you, not failed: its card shows the question, its terminal stays open until you answer there, and the run resumes. It fails only when its agent exits, or when nobody answers for 4 hours. A worker link whose run has ended says so, with a link to the run on the board, instead of spinning.
