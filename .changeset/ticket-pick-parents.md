On the ticket board's Pick tab, a parent folds the tickets under it away and starts folded, remembered in the browser, and Expand all opens every parent with the sections. A parent's checkbox picks every ticket under it, at any depth, that is not on the queue already, and shows part ticked when only some are picked. A parent is never queued itself, so Select all and a section's checkbox leave it out too. A parent that is not yours now has the same checkbox.
