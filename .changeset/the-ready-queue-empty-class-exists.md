The `ready-queue-empty` decision class exists (a11ign/agent-org#910, Move 3 of a11ign/a11ign#4505): whether any shelved row is promotable can be decided by a one-shot run, Haiku by default and Sonnet when the provider picks it or answers under its floor. `none-promotable` (also the default) posts the reason on each examined row, `promote` posts and sets `ready` only on a row whose Open-check was re-read at the head the order names, and `escalate` writes nothing and returns the order to the standing seat. The class is a file; `seatModeOf("ready-queue-empty")` stays `seat` until a project says otherwise.
