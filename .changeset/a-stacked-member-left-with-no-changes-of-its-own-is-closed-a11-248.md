A member of a stack that holds nothing of its own is closed (A11-248). When the member below it merged and the board has merged the default branch into it, a later sweep reads its files; if the list is complete and none is a change of its own (none, or only `.acceptance/` and `.changeset/`), the board closes it with a comment naming the merged member and says so on the card ("#N closed: everything it held merged with #M"). A close the host refuses is shown with its reason and tried again on the next sweep; a code host that cannot close says the pull request is to be closed. The code host contract is 1.23: `closePull`, optional.
