The stalled-claim pass now evaluates EVERY declared tracker's claimed rows, not only the home tracker's (a11ign/agent-org#747). It read the home tracker's `in-progress` rows alone, so no holder of an `a11ign/agent-org` row was ever nudged: the other trackers' rows reach it with the same readings, the same memory file and the same orders the home rows get. Their nudge memory is kept under `<key>#<row>` (`agent-org#476`, so the home tracker's `476` is another entry), and their order subjects and delivery keys are namespaced the same way (`row-agent-org#476`), with the prompt saying which repository its number is of. A tracker whose rows or claimed-row comments could not be read is said as unread on the tick's log and its memory is kept; it is never read as "no claim". A second tracker's RELEASE is withheld and said so, because `wake.ts`'s `stillHolds` and `row-claim decline` read the home repository's row and would refuse it as stale on every tick until a11ign/agent-org#834 lands; the holder is nudged and the claim stands. The idle-holder interval is unchanged: 10 minutes (`STOPPED_CLAIMANT_MINUTES`) for a stopped holder with no pull request, and 120 minutes (`STALL_INTERVAL_MS`) for the no-progress clock of a working one.
