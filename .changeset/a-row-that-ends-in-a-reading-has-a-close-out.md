A row that ends in a reading now has a close-out (a11ign/agent-org#1536). A worker whose claim names no pull request (`Claimed-nothing:`) closes its row with `worker:state done <row> --met=<item>:<comment>,...`, naming each Done-when item it reads as met and the comment that holds the reading. The row is closed with that list as its closing comment, and the worker is released. A `done <row>` with no `--met` is refused (`missing-met`), and so is a reading that leaves a Done-when item unmet (`unmet-done-when`) or names a comment not on the row (`unknown-comment`): nothing is written and nothing is closed. A `done` on a claim with an open or merged pull request reads exactly as before. `verifiedCloseOrder` (`idle-claimant.ts`) decides when an `in-progress` row whose claimant has been idle for 15 minutes after its own `VERIFIED` or "Done-when … met" comment should be ordered closed to `product-manager`. Neither the close-out nor `verifiedCloseOrder` is wired into the live claim-stall tick yet (`claim-stall-tick.ts` does not compute the reading for a `Claimed-nothing:` claim); that wiring is a follow-up row.
