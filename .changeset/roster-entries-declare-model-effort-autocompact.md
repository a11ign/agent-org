A persistent seat's roster entry may declare `model`, `effort` and `autocompact`, and the seat launcher starts the seat with them (a11ign/a11ign#4740, the chairman's direction on #4627: a restart of the liaison threw away his `/model claude-haiku-5-5` and `/effort high`, because a seat started with the fixed `SEAT_START_FLAGS`). `persistentEntries` returns the fields with the name and brief; `startSeat` takes `--model` and `--effort` from them when present and adds `--autocompact <n>` only when `autocompact` is present, every other flag unchanged, so an entry declaring none starts with the argv it always had. A malformed value (a model that is not an id, an effort outside `low`..`max`, a window that is not a positive whole number) is a `SEAT NOT STARTED <name>: roster entry <name>: <field> ...` line for that seat only, never a default and never a throw that would stop every seat. `autocompact` is the WINDOW `--autocompact` takes, which compacts about 35,000 tokens below it, so a Haiku seat declares `HAIKU_AUTOCOMPACT_WINDOW_TOKENS` (130,000, a trigger at 95,000), not the 90,000 in the direction (a trigger at 55,000, under the liaison's current 59k).
