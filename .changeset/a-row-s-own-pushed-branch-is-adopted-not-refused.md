A claim that meets an existing local branch of its own row adopts it, with its commits, when an earlier claim record names that branch or its trailing row number is this row's and origin holds it: a row the gate released is no longer refused its own pushed work. Another row's branch, a local-only branch no record names, and a branch a tree already stands on are still refused, and a claim that loses keeps an adopted branch rather than deleting it.
