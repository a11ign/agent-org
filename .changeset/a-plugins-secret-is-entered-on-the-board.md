A plugin's secret can be entered on the board's Plugins page (A11-445). The Linear key and the Telegram bot token are write-only password fields once the plugin is installed: the instance stores the value in a mode-600 file or the macOS Keychain, points the setting at it when it named no place, runs the plugin's own check and shows what it found. The value is never shown again, and is in no answer, log line or later read. A plugin with such a secret now has an Install button; one whose secrets are all set by commands still shows the commands.
