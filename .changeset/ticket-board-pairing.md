The ticket board no longer puts a secret in its URL, and a browser pairs once rather than at every start. A browser that has not paired is shown a pairing page: the new `agent-org ticket:pair` prints a one-time code, good once within 10 minutes and spent by five wrong guesses, and typing it gives the browser a session of its own as an HttpOnly cookie that lasts a year and survives restarts. The board keeps only the sessions' hashes, in `<stateDir>/tickets/browsers.json`, and deleting that file unpairs every browser. A script sends the board's key from `<stateDir>/tickets/board.key` as `x-ticket-token`, where it used to read a token from the board's output. Both files have mode 600, and the board refuses a key file another user owns or can read. `ticket:serve` prints the plain URL, and a code only when its output is a terminal. A request body that is not a JSON object, or is over 64 KB (1 KB for pairing), is a 400, and a key header with bytes outside ASCII is refused rather than crashing the board.
