The board UI has a "Search tickets" palette (A11-387). On an instance whose tracker can search, ⌘K / Ctrl+K on any page, or the new button at the top of the sidebar, searches every open ticket, whoever holds it and whatever its project. The palette also matches runs in the queue by key and title. Open ticket goes to Tickets with the ticket ticked and ready to queue, and a banner there leads back to the project and Assignee scope you came from. View run goes to the run's page. The palette lists the 3 tickets you opened from it most recently. Nothing changes on an instance whose tracker cannot search.
