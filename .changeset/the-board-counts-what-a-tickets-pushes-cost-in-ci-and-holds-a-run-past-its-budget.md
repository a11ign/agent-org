The board now reads what each ticket's pushes cost in CI (A11-261). The code host contract is 1.22: an optional `readBranchCi` reads the workflow runs on a ticket's branch with each job's runner labels and times (the GitHub plugin asks `actions/runs` and each unsettled run's jobs, re-run attempts included, and reads a completed run once). The board adds up each job's minutes rounded up to a whole minute and weighted as GitHub bills (macOS ×10, Windows ×2, other hosted runners ×1, self-hosted none), keeps a total per run and per ticket, and a run's card shows `CI: 3 pushes, 48 jobs, ~184 min`, with the ticket's total when it differs. A new host-file key, `tickets.ciBudgetMinutes` (300 by default, 0 for none), sets the weighted minutes a ticket may run: past it the worker is told once in its pane to batch its pushes and the card says the ticket is over budget; at twice it, and at each further whole budget, the board holds the run by itself. A live run is stopped and queued again as an update drain stops one, keeping its Claude session, and starts its next round a pass later with the reason and the push-once rule at the head of its brief; no person is asked and the hold counts toward no round cap. A code host plugin of contract 1.21 reads no branch's CI, so the board shows and holds nothing on it.
