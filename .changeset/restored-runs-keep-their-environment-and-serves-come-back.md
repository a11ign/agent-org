A run whose pane herdr restored without its environment is started again with it, and the board's and the terminal's tailnet serves are put back by the instance. herdr restores a pane's directory and Claude session, not the `AGENT_ORG_TICKET`, `AGENT_ORG_TICKET_BRANCH` and `AGENT_ORG_TICKET_HOST` the board gave `workspace create`, so after the 2026-10-25 reboot the gh wrapper refused a resumed run's `gh pr create`. Before a run is resumed the board now reads its Claude process's environment (`herdr pane process-info`, then `/proc/<pid>/environ`); a run that lacks a key is closed and started again in the same folder with `claude --resume`, the environment the board sets at start (`runEnvOf`, shared with `start()`) and the resume prompt, and its card says "its environment was restored". A run that is working is left alone until it first sits at a prompt; an environment that cannot be read leaves the run alone. The instance also checks the `ui` and `terminal` serves in its first pass and every 25 s or more after, serves again a free port, reports a port another entry holds (never replacing it), and says each change once in its log; `agent-org doctor` already fails a tailnet port that is not served. The event tunnel (`event-tunnel.ts up`) resolves the exposure from the instance's host file when `AGENT_ORG_HOST`'s file names none, waits up to 45 s for the exposure to be ready, and its unit is started again after 30 s on failure with no limit on the tries. A11-279.
