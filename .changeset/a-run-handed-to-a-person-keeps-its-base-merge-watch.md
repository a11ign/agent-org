A run the board handed to a person (Needs you) is watched for its base like every finished run: a pull request of it that conflicts or is behind has `updateBranch` asked, where before the watch skipped it and `a11ign/agent-org#1933` sat `CONFLICTING` for a day with nothing in the log. A real conflict on such a run starts no round, since the run is a person's; the log says `held`, the card of any finished run with a conflicting open pull request says `<pull request> conflicts with <base>`,, and Respond to review carries the conflict into its round.
