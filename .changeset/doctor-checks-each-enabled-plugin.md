`agent-org doctor` checks each plugin `tickets.plugins` names, as a worker's session gets it: one line per plugin, ok when it loads and its declared contract matches the host's keys, and a failure named with the plugin when it does not load or a contract row does not match (A11-140). It reads the same record the Settings page and the run start read, so the three cannot disagree. A contract row about a plugin the host does not enable is listed in `plugin contract`. When Claude Code's install record cannot be read, each plugin is shown as not checked, which does not fail.
