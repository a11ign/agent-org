A new-ticket request takes a placement, Auto or Manual (A11-199). `POST /api/writer` accepts `placement: "auto" | "manual"`. Under Auto the writer chooses the ticket's project, repository, goal, priority and parent from the request, and the priority is no longer fixed at 0 when the request names none (it is chosen from the tracker's numbers). Under Manual the writer uses each choice the request names as given, and chooses the rest; leaving a choice out means the writer chooses it, and `"none"` is a priority the person chose. A body with no `placement` is read as its choices imply (Manual when it names any of the five, else Auto), so a caller from before placement keeps its behaviour except that a request naming no priority now has the priority chosen for it. Anything else is refused with `placement must be "auto" or "manual"`, and an Auto request that names a choice is refused with `auto placement names no project, repository, goal, priority or parent: send placement manual to name them`. `/api/writer` shows each run's `placement` (a run stored before it is read by the same inference), and each ticket a run made carries its `title`, `priority` and `project` as the tracker held them. The request's limits move to `src/ticket-mode/writer-limits.ts`, which the board's page can import.
