A ticket the tracker holds In Progress that has no run on the board and holds a queued run back is no longer left for 15 hours (A11-253 held A11-254 and A11-256 that long, with all ten pull requests merged). Each feedback sweep completes it when every pull request it links has merged and one of them closes it, and otherwise queues it on the saved model and effort from `choice.json`, without a plan run; a ticket another instance claimed is left to that instance, and a refusal is said once and tried again. The stale-wait sentence on the Runs page and in `doctor` now names the action the board takes (`completes it`, `queues it`, or that a person decides) instead of only saying nothing is working on the ticket.
