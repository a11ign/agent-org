A claim whose row number is in another declared tracker is refused with the way out, not a bare refusal. An undeclared key that is a declared repository's `owner/repo`, name or owner names the declared key (`--tracker=`) that repository has, and lists every match when an owner owns two. A 404 on the row read names the other declared trackers. The 404 stays `claim-refused`, because GitHub also answers 404 for a repository the token cannot see; a rate limit gets no such line (a11ign/agent-org#1562).
