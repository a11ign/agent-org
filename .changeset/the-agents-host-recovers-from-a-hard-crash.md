The agents host recovers from a hard crash by itself (a11ign/a11ign#5127). `src/crash-recover.ts` is run once at boot by `a11ign-crash-recover.service` (shipped as `host/crash-recover.service.in`, `Before=` the tick timer). It detects an unclean shutdown (journald's "uncleanly shut down" or a pstore record not seen before) and then: restores every tracked file that is 0 bytes on disk and non-empty at `HEAD` in the primary and tool checkouts; moves empty git object, ref, `FETCH_HEAD` and worktree-metadata files aside to `~/crash-<date>/`, runs `git fetch --refetch` and `git fsck --connectivity-only`; resumes each pane whose agent is gone with `claude --resume <session id>` plus the org's launch flags (a seat's from `sessions.json`, a worker's `agentArgs` with model and effort from its last traced turn); closes dead `reviewer-<n>` panes for the gate to respawn; runs `systemctl --user reset-failed`; and posts one announcement through `chairman:reply`. A second hard crash within seven days wakes `ceo` as a hardware-health question. `writeFileAtomic` (temp file, fsync, rename, directory fsync) is exported for the state writers. Flag: `host.crashRecover` in `host.json`, on when absent; revert is disabling the unit. A clean boot changes nothing.
