A repository of the organisation that this machine has not cloned is cloned by the board when a plan or a worker names it, so work in a new repository is no longer a `wrong-repo` on a person. The organisation is the owner of the machine's clones' `origin` remotes; its live repositories (not archived) are listed by the code host's `repositories` group as the account the board acts as (`src/ticket-mode/org-repos.ts`). A planner's brief offers those with no clone beside the clones, and a plan that names one has it cloned (`placeUncloned`, `src/ticket-mode/pool-settle.ts`); a plan that names a repository outside the organisation, or one the board cannot clone, is refused as before. A run that ends `wrong-repo` naming a repository of the organisation is moved there, cloned first when it must be, and queued again with no person asked (`settleWrongRepo`); a `wrong-repo` naming anything else, a run already placed there, or a run already moved twice still reads Needs you. Retry (`retryRun`, `src/ticket-mode/pool-actions.ts`) closes a parked run's workspace and queues it, in the organisation repository its `wrong-repo` named, and a run it cannot retry answers 409 with the reason instead of a 200 over an unchanged run. The board's sweep clones every live organisation repository with no clone (`cloneMissing`), and doctor lists them (`organisation clones`).
