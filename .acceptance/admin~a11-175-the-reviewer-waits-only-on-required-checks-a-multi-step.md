## What it is

The queue halted on 2026-10-23 for three reasons: a reviewer never started because a check that is not required was red (a11ign/lab#144), a multi-step ticket (A11-160, step 3 of 9) held every path of its nine-step plan so A11-173 and A11-174 sat Blocked on files its pull request does not touch, and a Partial pull request (#1824) was reviewed against the whole ticket's Done-when. The reviewer now waits only on the required checks, a run holds only its current step's paths, and a Partial pull request is reviewed against its step (A11-175).

## Change

- `src/work-gate/pr-orders.ts`: `settledGreenOf(pr, required)` counts only the required checks (every check when the list is null or empty, and a required check that has not reported is not settled); `unrequiredRedOf` names the checks that failed and are not required; `REVIEW_PULL_FIELDS` gains `body`.
- `plugins/github/reviews.ts`, `src/plugins/manifest.ts`, `src/ticket-mode/reviewer-port.ts`: `readReviewState` asks GitHub which checks are required (`isRequired(pullRequestNumber:)`, the form `pull-feedback.ts` reads) only when the rollup is not all green; core's `ReviewJudge` decides `settled` and `unrequiredRed`.
- `src/plugins/contracts/code-host.ts` (1.6: `ReviewState.unrequiredRed`), `contracts/reviewer.ts` (1.3: `ReviewBrief.step`), the fakes, the conformance suites and both plugins' declared contract versions.
- `plugins/atomic-reviewer/prompt.ts`, `port.ts`: the prompt names the checks left red in a first review, a reprompt and a re-review, and, for a step brief, says it is step N of M, quotes the step's section, states the ratchets' direction and heads the Done-when "for the last step (step M of M)".
- `src/ticket-mode/plan-step-sections.ts` (new, pure): the step sections of a plan, as `### Step <N>` headings with their own path bullets, or as the rows of a steps table (no paths).
- `src/ticket-mode/pool-start.ts`, `queue/queue-transitions.ts`, `queue-entries-and-outcomes.ts`, `queue-next-step.ts`, `board-view/view-types-and-filters.ts`: `Entry.stepPaths`, recorded with the plan's paths and carried to the next step and through a round.
- `src/ticket-mode/board-view/plan-steps.ts`, `pull-status-and-notes.ts`: `currentStepOf`, `currentStepPaths`, `partialStepOf`; `footprintOf` and `contested` hold the current step's paths and the open pull requests' files.
- `src/ticket-mode/pool-reviewers.ts`, `pool-ticket-text.ts`: `briefOf` carries the step read from the pull request's body, with the plan's section from the downloaded plan files.
- `src/ticket-mode/worker-files.ts`: the planning briefs tell a planner to write a `### Step <N> of <M>` section with its own paths for a numbered plan.
- `README.md`: the reviewer paragraph and the overlap paragraph.

## How it is proven

Each acceptance line of the ticket is proven by a named test:

- the reviewer starts once the required checks have settled green, and a failing check that is not required does not hold it: `A11-175: settledGreenOf counts only the required checks, and every check when the list is null or empty` (`src/work-gate/pr-orders.test.ts`), `A11-175: readReviewState is settled when the required checks are green and an unrequired one is red, and reads isRequired only when the rollup is not green` and `A11-175: a list of required checks GitHub would not give, or that is empty, counts every check, so the reviewer waits as it did` (`plugins/github/code-host.test.ts`), `A11-175: a pull request whose only red check is not required gets its reviewer` and `A11-175: a pull request with a required check red, running or unreadable is not started, and the board says it is waiting for checks` (`src/ticket-mode/pool.test.ts`, the real plugin over a scripted `gh` and the real gate), `A11-175: ticket:review starts a reviewer past a red unrequired check` (`src/ticket-mode/review-command.test.ts`, `plugins/atomic-reviewer/review-command.test.ts`);
- a failing check that is not required is named in the reviewer's brief: `A11-175: the prompt names the unrequired red checks and says they did not hold the review, in a first review, a reprompt and a re-review` (`plugins/atomic-reviewer/prompt.test.ts`), `A11-175: the started prompt names the unrequired red checks the code host reports, and the reprompt and a re-review do too` (`plugins/atomic-reviewer/port.test.ts`), and the code host contract suite takes `unrequiredRed` only as a list of names (`A11-175: the fake reports the unrequired red checks it is told of ...`, `src/plugins/fakes/code-host.test.ts`);
- a multi-step ticket holds only its current step's paths and its open pull requests' files: `src/ticket-mode/plan-step-sections.test.ts` (step headings with their bullets, and A11-160's table rows with no paths), `A11-175: a finished step-3 run holds its step's paths and its pull request's files, not the plan's`, `A11-175: a step with no paths of its own holds only its open pull request's files, as A11-160's does ...`, `A11-175: a running step with no paths and no pull request holds the whole plan ...`, `A11-175: a running step holds its step's paths ...` and `A11-175: a queued later step contests only its step's paths ...` (`src/ticket-mode/board-view.test.ts`), `A11-175: a queued run's plan is read with the paths of each step section ...` (`pool.test.ts`), `A11-175: recordPaths records the step sections' paths ...` and `A11-175: the next step's run carries the step sections' paths ...` (`src/ticket-mode/queue.test.ts`), `A11-175: both planner briefs tell the planner to give each step ...` (`src/ticket-mode/worker-files.test.ts`);
- a pull request whose body says `Partial: step N of M` is reviewed against that step's section and the ratchets' direction, with the whole-ticket Done-when named "for the last step": `A11-175: partialStepOf reads the step from the body's Partial: line ...` and `A11-175: a run's current step is ...` (`src/ticket-mode/plan-steps.test.ts`), `A11-175: a pull request whose body says Partial: step 3 of 3 is briefed with step 3's section of the plan ...`, `A11-175: a step the plan numbers as a table row is quoted with its header ...`, `A11-175: a pull request without a Partial: step in its body is briefed as it always was ...` and `A11-175: the unposted-verdict reprompt carries the step ...` (`pool.test.ts`), `A11-175: a step brief quotes the section, states the ratchets' direction and heads the Done-when 'for the last step (step 9 of 9)'` and `A11-175: a step brief with no section says so ...` (`plugins/atomic-reviewer/prompt.test.ts`), `A11-175: a brief that names the plan step a pull request finishes reaches the prompt ...` (`port.test.ts`), and the reviewer contract suite hands a step brief to the reviewer (`src/plugins/fakes/reviewer.test.ts`).
