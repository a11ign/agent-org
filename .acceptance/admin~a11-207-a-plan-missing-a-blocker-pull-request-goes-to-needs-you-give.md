A planning brief lists every blocker of the ticket and every pull request of each, with its state, title and address, and marks the merged ones whose findings the board read as needing a line in the plan's `## What the blockers found` section (the check's own list), with the exact line form the check accepts. The board writes that same list beside the run's outcome file (`findings-given.json`), and the planner's Stop hook checks the plan against it before the planner ends. A plan that misses a pull request is refused once, in the planner's own session, naming the missing addresses; the plan it then writes is attached with no one asked. A second miss goes to Needs you, and the card names the missing pull requests and says one automatic retry was made. A blocker with no pull request needs no line, at the stop and at settle. The tracker contract is 1.6: `Blocker` may carry the title of each pull request it links, which the Linear plugin fills from the GitHub attachment's title.
