The `board-disagrees-with-reality` order is keyed per (row, question) pair behind `orgHealth.boardTruthPairKey` (default OFF). With the flag OFF, `boardTruthReading`'s discriminator is the original set-keyed string, and the code path that produces it is unchanged. With the flag ON, `boardTruthPairOffers` reads the canary, runs `boardTruthPairStep` over the pairs on the board, writes `board-truth-pairs.json`, and `boardTruthReadings` emits one tripped reading per offered pair, keyed `board-disagrees-with-reality@<row><question>` (with `:<n>` on a re-offer). A pair is offered on first sight, or when it returns more than `BOARD_TRUTH_CLEAR_MINUTES` (120) after its last sighting; a standing pair is not re-offered. An unreadable canary reads the flag OFF; a pairs file that cannot be read or written, or holds an entry that is not `{offers, lastSeen}` for a row and question, makes no board order that tick and is not rewritten. `board-disagrees-with-reality` joins `MACHINERY_SIGNALS` (it was absent) with a null value, because the canary's facts carry no board audit.
