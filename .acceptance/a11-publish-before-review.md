A machine where people review publishes a run before its review: `tickets.providers.publish.when: "awaiting-review"`, set with `agent-org plugin config slack when=awaiting-review`. Under it, a run out of draft (`reviewed` or `ready-pr`) can be ticked for Publish once every open pull request was read at its head and waits on its review alone, with no required check red or running. A draft, a run not read yet, a parked run, one being published and one already published cannot. The board's tick, Run detail's Publish button, the "publishing off" line and `POST /api/publish` all ask `publishable`, and `/api/queue` carries `publishWhen` so the page ticks what the server accepts. Absent, `when` is `ready-to-merge`, today's behaviour. `when` is a setting of the publisher concern, like the reviewer's `required`: valid under any provider, kept on uninstall, refused by name for any other value, shown on the Plugins page's Publisher card (config-schema) and in doctor's publisher row.

Mutation: eighteen changes were made in turn, each restored after, and each turned one or more of the new tests red. In `publishable`: `when` ignored; the review-only wait dropped; a running check, a red check or an unread head let through (`waitsOnlyOnReview`); `ready-pr` left out of, or `draft-pr` added to, the outcomes out of draft. A published `ready-pr` run read as Awaiting review again. Publishing not shown for a run awaiting review. `queuePublish`, the server's `/api/publish` and `/api/queue` each dropping the setting. The reader accepting any value, always reading the default, or not taking `when` as the concern's setting. Doctor's row not saying it. "publishing off" ignoring `when`. The Runs page's tick ignoring `queue.publishWhen`.

Consumer-declaration: one new optional host-file key, `tickets.providers.publish.when` (`"ready-to-merge"` or `"awaiting-review"`); absent it reads as today. `/api/queue` gains `publishWhen`; the page reads its absence (an older instance) as `ready-to-merge`. A `ready-pr` run with `published` now reads Published, which no run could have before, since only Ready to merge runs were published.
